# Calix AI

A community-learning Ekegusii AI assistant.

## Current foundation
- Mobile-friendly chat interface
- Teach vocabulary (Ekegusii word/phrase, English meaning, optional example)
- Local browser storage for saved words
- Look up saved vocabulary by typing the word into chat

## Important current limitation
This is an early prototype: vocabulary is saved only in the current device/browser. It is not yet shared across users and the live AI model is not connected. The next steps are to connect a shared cloud database and a secure AI backend. Never place API keys in frontend files.

## Run
Open `index.html` in a browser or deploy as a static site.
